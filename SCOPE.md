# SCOPE.md &middot; Project Scope & Roadmap

## In-Scope Features (Implemented v1.0.0)
- Cozy Japanese 3D diorama garden with cedar planter box and checkerboard tiles
- Continuous smooth Catmull-Rom tube snake body in jade mochi green
- Anime dragon head with snout, glossy bead eyes, rosy blush cheeks, cream horns, and whiskers
- Backward-slanted dorsal spikes along spine with size gradient tapering toward the tail
- Fluffy cloud tuft tail end
- Realistic spherical apple with wooden stem, emerald leaf, and ambient hover bobbing
- Turntable orbit camera with pause toggle and pointer drag navigation
- Autonomous pathfinding AI with tail protection and cycle survival heuristic
- Responsive HUD pills with Fredoka typography
- Standalone PWA manifest and compact square OpenGraph link preview

## Future Backlog Ideas
- Toggleable manual keyboard and swipe controls for playable mode
- Multiple garden biomes such as zen gravel raked sand, sakura cherry blossom, and night lantern diorama
- Atmospheric weather particles like gently floating cherry blossom petals or fireflies
- Sound effects using Web Audio API for apple munching and tranquil wind chimes

## Out-of-Scope Boundaries
- Heavy physics engines (such as Cannon.js or Rapier)
- Multiplayer networking or backend database synchronization
- Framework migrations to React, Next.js, or Tailwind CSS
